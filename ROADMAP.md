# Roadmap

A Cartografia é uma experiência em modos — uma progressão, não versões
concorrentes:

```
Sistema Vivo → Ponto Cego → Mundos → Anatomia → Casos → Método → Arquivo
```

## Publicado

- **Sistema Vivo** — a rede que nasce, respira e reage às sete lentes.
- **Ponto Cego** — o sistema compreendido.

## Em construção

- **Mundos** — cada organização como um planeta próprio: hospital, logística,
  escritório, call center, startup. Ao entrar, mergulha-se em camadas.
- **Anatomia** — remover camadas do sistema, uma a uma:
  `estrutura → processos → pessoas → dados → dependências → comportamento`.
- **Casos** — projetos completos e documentados.
- **Método** — a Cartografia Operacional explicada (as sete lentes, o vocabulário).
- **Arquivo** — documentos, diagramas e estudos.

## Princípio

Cada modo nasce quando tem conteúdo real para mostrar — não quando surge um
nome interessante.
